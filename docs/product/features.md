# 產品功能 - 塔羅日記願景

## 1. 核心塔羅與雷諾曼
- **日記記錄**：記錄每日抽牌與個人感悟。
- **牌義庫**：詳細的偉特塔羅與雷諾曼牌義圖書館。
- **AI 解牌**：基礎的 AI 生成抽牌解讀。

## 2. 神諭者（互動式 AI）[開發中]
- **上下文對話**：針對解讀內容提出後續問題。
- **對話紀錄**：儲存與日記條目關聯的對話內容。
- **語氣控制**：選擇不同的 AI「神諭者」人格（例如：神秘、心理、實用）。 [待規劃]

## 3. 神秘儀表板 [規劃中]
- **共時性追蹤**：視覺化重複出現的牌組與模式。
- **元素平衡**：顯示火、水、風、土元素分布的圖表。
- **情緒關聯**：將日記條目的情緒與抽出的牌進行映射。

## 4. 符號深度探索 [規劃中]
- **互動式符號**：點擊牌面特定部分以了解符號（例如：寶劍皇后上的蝴蝶）。
- **符號庫**：可搜尋的赫密斯與神秘學符號資料庫。

## 5. 分享與社群 [規劃中]
- **每週全球主題**：所有使用者共享的每週一牌。
- **精美導出**：生成高品質圖片以分享解讀。
